Appium Flages:

--address: Specifies the IP address on which the server will run.
--port: Defines the port number the server will listen to.
--session-override: Allows the server to override existing sessions when a new one starts.
--no-reset: Prevents clearing app data between test sessions.
--log-level: Sets the verbosity of server logs (e.g., info, debug, error).
--log-timestamp: Toggles timestamps in log outputs for better tracking.
--relaxed-security: Enables less restrictive security settings for testing purposes.
--default-capabilities: Defines default session settings when none are provided.



###################################################################################################################

Appium Server: A Node.js-based server that receives requests and interacts with the mobile device.
Appium Client: The code written in Java, Python, or other languages that sends commands to the Appium Server.

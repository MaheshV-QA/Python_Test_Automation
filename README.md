# Python Test Automation Project

## Project Structure

- **Notes**: Contains PDF documents with Python interview questions and notes.

- **Python**: Covers various Python topics, including:
  - **Advanced_Topics**: Examples of decorators, exception handling, file handling, and more.
  - **Basics**: Basic Python concepts (currently empty).
  - **Data_Structure**: Examples of data structures like lists, tuples, sets, and dictionaries.
  - **Functions**: Examples of Python functions, including lambda functions, map, filter, reduce, and more.
  
  - **OOPS**: Object-Oriented Programming concepts, including inheritance, polymorphism, abstraction, and encapsulation.

- **Python_API_Testing**: Scripts for API testing using the `requests` library.

- **Python_Appium_MobileTesting**: Contains Appium-related files for mobile testing.

- **Python_Interview_Coding**: Coding challenges and solutions for interview preparation, including number and string-related problems.

- **Python_Selenium_Automation**: Scripts for web automation using Selenium.

For more detailed information, you can refer to the specific directories and files within the project.

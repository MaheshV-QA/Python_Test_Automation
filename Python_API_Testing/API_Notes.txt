In software testing, assertions are statements used to verify expected outcomes, and they come in various formats and types, 
including hard assertions (stop test execution on failure) and soft assertions (continue execution even on failure). 

Types of Assertions:
Hard Assertions:
These assertions cause the test to fail and stop execution if the assertion condition is not met. 
Common examples include assertEquals(), assertTrue(), assertFalse(), assertNull(), and assertNotNull(). 

Soft Assertions:
These assertions allow the test to continue execution even if the assertion condition fails. 
They are useful for verifying multiple conditions in a test case without prematurely stopping the test. 
The assertAll() method can be used for soft assertions

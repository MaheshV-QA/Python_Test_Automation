### **List, Tuple, Set, and Dictionary in Python (With Functions)**  

#### ** List (Ordered, Mutable, Allows Duplicates,hetrogeneous)**  
A **list** is a collection of elements that maintain order and can be modified.  

**Common Methods:**  
- `append(item)` → Adds an item at the end.  
- `insert(index, item)` → Inserts an item at a specific position.  
- `remove(item)` → Removes the first occurrence of an item.  
- `pop(index)` → Removes and returns an item at a given index.  
- `sort()` → Sorts the list in ascending order.  
- `reverse()` → Reverses the order of elements.  
- `count(item)` → Counts occurrences of an item.  
- `index(item)` → Returns the index of the first occurrence of an item.  
- `extend(iterable)` → Adds multiple elements from another iterable (list, tuple, etc.).  
- `clear()` → Removes all elements.  

#######################################################################################################

#### **2⃣ Tuple (Ordered, Immutable, Allows Duplicates)**  
A **tuple** is a collection similar to a list, but it cannot be modified after creation.and maintains order.  

**Common Methods:**  
- `count(item)` → Returns the number of times an item appears.  
- `index(item)` → Returns the index of the first occurrence of an item.  

#############################################################################################################

#### **3⃣ Set (Unordered, Mutable, No Duplicates)**  
A **set** is a collection that stores unique elements in an unordered manner.  

**Common Methods:**  
- `add(item)` → Adds an item.  
- `remove(item)` → Removes an item (raises an error if not found).  
- `discard(item)` → Removes an item (does not raise an error if not found).  
- `pop()` → Removes and returns an arbitrary item.  
- `clear()` → Removes all elements.  
- `union(set2)` → Returns a new set with all elements from both sets.  
- `intersection(set2)` → Returns a set with common elements.  
- `difference(set2)` → Returns a set with elements not in the second set.  
- `issubset(set2)` → Checks if all elements are in another set.  
- `issuperset(set2)` → Checks if the set contains all elements of another set.  

#############################################################################################################

#### **4⃣ Dictionary (Key-Value Pairs, Mutable, No Duplicate Keys)**  
A **dictionary** stores elements in key-value pairs. It is mutable and does not allow duplicate keys. maintains order.

**Common Methods:**  
- `keys()` → Returns all keys.  
- `values()` → Returns all values.  
- `items()` → Returns key-value pairs.  
- `get(key)` → Returns value for a key (returns `None` if the key doesn’t exist).  
- `pop(key)` → Removes and returns a key-value pair.  
- `popitem()` → Removes and returns the last inserted key-value pair.  
- `update(dict2)` → Updates the dictionary with another dictionary’s key-value pairs.  
- `clear()` → Removes all elements.  
- `setdefault(key, value)` → Returns the value of a key; if the key is missing, it inserts the key with the given value.
